## Skynet Rock Paper Scissors
Themed Rock Paper Scissors browser game with a retro-futuristic aesthetic reminiscent of the early 90s. 

### Note
I'm fairly certain this was my first coding project that had any kind of interactivity. I look back on it fondly, but as a consequence of my inexperience at the time object sizes are hard-coded which breaks on smaller screens (tablets and below). It's an easy fix, but it feels wrong to overhaul my very first "fun" project.
